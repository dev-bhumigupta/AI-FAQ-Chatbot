🤖 AI FAQ Chatbot

An AI-powered FAQ chatbot Built using Python, Streamlit, and Machine Learning (TF-IDF + Cosine Similarity).

Features
Interactive chatbot
Machine Learning–based FAQ matching using TF-IDF and Cosine Similarity
Built with Streamlit
Fast and responsive
Technologies Used
Python
Streamlit
Scikit-learn
NLTK
Pandas
How It Works
Loads FAQ data from faq.json.
Preprocesses the user's question.
Converts questions into TF-IDF vectors using Scikit-learn.
Uses Cosine Similarity to compare the user's question with the stored FAQs.
Returns the answer with the highest similarity score.
If no good match is found, it displays a friendly message asking the user to rephrase the question.
